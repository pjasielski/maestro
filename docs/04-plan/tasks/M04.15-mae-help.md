## Description

Eleven commands, no obvious entry point, and a framework whose premise is that order is flexible — liberating for an experienced user, paralyzing for a new one. External developer feedback asked for help; the valuable half of the request is not a command list (that is the README) but **"what should I run right now"**, which Maestro can answer mechanically from the filesystem.

**Build this first in M04.** Its state table — "user is at state X, skill Y is relevant" — *is* the auto-trigger heuristic that M04.02's frontmatter convention must encode. Building it first gives M04.02 a tested state machine instead of a guess.

## Acceptance Criteria

- [x] `/mae-help` (bare) reports current project state and suggests the next command, derived from what exists on disk:

  | State | Suggestion |

  | No `docs/01-explore/`, no session | `/mae-explore` |
